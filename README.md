# Cell Signaling Webquest (Biology A)

A static web page. No build step is needed.

- `index.html` is the webquest.
- `media/` holds the 4 videos and 3 images the page uses. It must stay next to `index.html`.
- `vercel.json` holds simple Vercel settings.

## Deploy on Vercel
1. Import this GitHub repository into Vercel.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty. Root Directory: `./`
3. Deploy.
